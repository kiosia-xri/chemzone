Κάψουλα 02 · Θερμοχημεία

Ενθαλπία, Νόμοι θερμοχημείας και τιπς για λύση ασκήσεων σε χρόνο dt

5 βασικές ιδέες, ένα πλήρες παράδειγμα με δύο τρόπους λύσης, και ένα γρήγορο τεστ για να δεις αν κόλλησαν.

⏱ 6 λεπτά ανάγνωση ✓ 2 τρόποι λύσης ✓ 3 ερωτήσεις ελέγχου
Η θεωρία

5 ιδέες που χρειάζεσαι

01

ΔΗ είναι το ποσό θερμότητας που εκλύεται ή απορροφάται όταν αντιδρούν και παράγονται τόσα mol ουσιών όσα είναι οι συντελεστές των σωμάτων.

02

Εξώθερμη: ελευθερώνουν θερμότητα, ΔΗ < 0, Η(προϊόντων) < Η(αντιδρώντων)
Ενδόθερμη: απορροφούν θερμότητα, ΔΗ > 0, Η(προϊόντων) > Η(αντιδρώντων)
Θερμοουδέτερη: ΔΗ ≈ 0, ούτε ελευθερώνουν ούτε απορροφούν θερμότητα

⚠️ Προσοχή: πρότυπες συνθήκες σημαίνει P = 1 atm, θ = 25°C, και για διαλύματα συγκέντρωση c = 1M.
💡 Να θυμάσαι: κατά την εξουδετέρωση ισχυρού οξέος με ισχυρή βάση ελευθερώνεται θερμότητα ίση με 57,1 kJ (ανά mol νερού που σχηματίζεται).
03

Η πρότυπη ενθαλπία σχηματισμού ενός στοιχείου στη σταθερότερη μορφή του είναι ΔΗ°f = 0.

04

Νόμος / Αρχή Lavoisier-LaplaceΑν αντιστρέψεις μια αντίδραση, το ΔΗ αλλάζει πρόσημο. Αν πολλαπλασιάσεις τους συντελεστές, πολλαπλασιάζεται κι αυτό.

05

Νόμος Hess: το ΔΗ μιας αντίδρασης είναι το ίδιο, όποια διαδρομή κι αν ακολουθήσεις. Άρα μπορείς να προσθέτεις/αφαιρείς γνωστές αντιδράσεις (με τα ΔΗ τους) για να "χτίσεις" την άγνωστη.

Παράδειγμα

Βρες το ΔΗ σχηματισμού του CH₄

Στόχος: C(γρ) + 2H₂(g) → CH₄(g), ΔΗf = ;
(1) C(γρ) + O₂(g) → CO₂(g), ΔΗ₁ = −393,5 kJ
(2) H₂(g) + ½O₂(g) → H₂O(l), ΔΗ₂ = −285,8 kJ
(3) CH₄(g) + 2O₂(g) → CO₂(g) + 2H₂O(l), ΔΗ₃ = −890,3 kJ

Τρόπος 1 — Νόμος Hess (συνδυασμός αντιδράσεων)

Στον στόχο, το CH₄ είναι προϊόν (δεξιά). Στην (3), το CH₄ είναι αντιδρών (αριστερά) — λάθος πλευρά. Κανόνας: όποτε μια ουσία είναι στη λάθος πλευρά, αντιστρέφεις ολόκληρη την αντίδραση.
(3′): CO₂ + 2H₂O → CH₄ + 2O₂, ΔΗ₃′ = +890,3 kJ — το πρόσημο αλλάζει (Lavoisier-Laplace)
Αριστερά: C + O₂ + 2H₂ + O₂ + CO₂ + 2H₂O
Δεξιά: CO₂ + 2H₂O + CH₄ + 2O₂
Το 2× στο (2) γιατί χρειάζεσαι 2 H₂O για να ταιριάξει με την (3′)
CO₂, 2H₂O και 2O₂ υπάρχουν εκατέρωθεν — σβήνουν. Μένει: C + 2H₂ → CH₄ — ακριβώς ο στόχος!
ΔΗf = ΔΗ₁ + 2·ΔΗ₂ + ΔΗ₃′ = (−393,5) + 2(−285,8) + 890,3 = −74,8 kJ/mol

Τρόπος 2 — Από πρότυπες ενθαλπίες σχηματισμού (πιο σύντομος)

Η (1) και η (2) είναι ήδη αντιδράσεις σχηματισμού: ΔΗf(CO₂) = ΔΗ₁, ΔΗf(H₂O) = ΔΗ₂, ΔΗf(O₂) = 0
ΔΗ₃ = ΣΔΗf(προϊόντων) − ΣΔΗf(αντιδρώντων)
ΔΗ₃ = [ΔΗf(CO₂) + 2ΔΗf(H₂O)] − [ΔΗf(CH₄) + 2ΔΗf(O₂)]
−890,3 = [(−393,5) + 2(−285,8)] − [ΔΗf(CH₄) + 0]
−890,3 = −965,1 − ΔΗf(CH₄)
ΔΗf(CH₄) = −965,1 + 890,3 = −74,8 kJ/mol — ίδιο αποτέλεσμα, λιγότερα βήματα
